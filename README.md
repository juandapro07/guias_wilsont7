# Semana 5: Cierre del Bloque 1 - Unidad de Emprendimiento (P05 y C05)

Este directorio contiene la consolidación del Bloque 1 de Bases de Datos NoSQL, implementando el modelo documental, las operaciones CRUD, las 10 consultas reproducibles, el esquema de validación estricto, índices únicos y el plan de migración a `schema_version 2`.

## Estructura de la Carpeta
- `docs/`: Contiene el modelo de datos (`modelo_p05.md`), la matriz de consultas (`matriz_p05.md`), las pruebas de calidad (`pruebas_calidad_p05.md`) y las respuestas de la comprobación individual (`respuestas_c05.md`).
- `scripts/`: Contiene los scripts ejecutables para la minibase C05 (`01_preparar_c05.js`) y el catálogo de consultas P05 (`02_consultas_p05.js`).
